Northwestern Turkic. The Kipchaks appear in the Kimek confederation on the Irtysh and, together with the Cumans, dominated the steppe from the Irtysh to the Danube between the 11th and 13th centuries. After the Mongol conquest the Golden Horde became largely Kipchak-speaking, and the khanates that followed it shaped the Tatars, Bashkirs, Crimean Tatars, Kazakhs and Kyrgyz of today.

## Commits on this branch

Each commit is one historical event.

- **c. 850 CE**: Kimek-Kipchak confederation on the Irtysh
- **c. 1050**: Kipchaks/Cumans dominate the western steppe: the 'Dasht-i Kipchak'
- **1242**: Golden Horde founded; its Mongol elite gradually shifts to Kipchak Turkic
- **1303**: Codex Cumanicus records the Kipchak/Cuman language

Run `git log --oneline kipchak/trunk` to see them together with the history they build on. The same list is in [`lineages/kipchak--trunk.md`](lineages/kipchak--trunk.md).
