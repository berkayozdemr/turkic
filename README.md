# <a href="https://commons.wikimedia.org/wiki/File:Flag_of_Bashkortostan.svg"><img src="https://upload.wikimedia.org/wikipedia/commons/thumb/3/3d/Flag_of_Bashkortostan.svg/120px-Flag_of_Bashkortostan.svg.png" alt="Flag of Bashkortostan" height="26"></a> Bashkirs

`kipchak/bashkir`

| | |
|---|---|
| **Self-name** | Bashqort · Башҡорт |
| **Where they live today** | Bashkortostan in the southern Urals, Russia |
| **Branch** | Kipchak: Northwestern Turkic, from the Black Sea steppe to the Altai. |

Close linguistic neighbours of the Tatars, described already by Ibn Fadlan in the 10th century. Bashkir clans came under Muscovite rule in the 1550s; whether by agreement or conquest is debated. Known for a strong tradition of horse breeding, wild-hive beekeeping and epic poetry such as Ural-batyr.

## Commits on this branch

Each commit is one historical event.

- **1557**: Bashkir clans accept Russian suzerainty
- **1919**: Bashkir Autonomous Soviet Republic

Run `git log --oneline kipchak/bashkir` to see them together with the history they build on. The same list is in [`lineages/kipchak--bashkir.md`](lineages/kipchak--bashkir.md).
