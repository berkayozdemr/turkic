# Old Uyghur line and the Western Yugurs

`old-uyghur`

| | |
|---|---|
| **Self-name** | Sarïg Yogïr |
| **Where they live today** | Sunan Yugur Autonomous County, Gansu, China |
| **Branch** | Old Uyghur line: The eastern Old Turkic line of the Uyghur Khaganate and the Qocho kingdom. |

A few thousand speakers, mostly Buddhist. Western Yugur is usually named as the living descendant of Old Uyghur, the language of the Uyghur Khaganate and the Qocho and Gansu Uyghur kingdoms, though its exact placement is debated. Some Yugurs speak a Mongolic language instead (Eastern Yugur).

## Commits on this branch

Each commit is one historical event.

- **c. 841 CE**: Uyghurs move south-west: Kingdom of Qocho (Turfan) and the Gansu Uyghurs

Run `git log --oneline old-uyghur` to see them together with the history they build on. The same list is in [`lineages/old-uyghur.md`](lineages/old-uyghur.md).
