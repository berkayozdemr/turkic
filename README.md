# Uyghurs

`karluk/uyghur`

| | |
|---|---|
| **Self-name** | Uyghur · ئۇيغۇر |
| **Where they live today** | Xinjiang Uyghur Autonomous Region, China; also Kazakhstan and Kyrgyzstan |
| **Branch** | Karluk: Southeastern Turkic, heir to the Karakhanid and Chagatai literary tradition. |

The oasis-city people of the Tarim Basin (Kashgar, Turpan, Hotan), writing in an Arabic-based script. Modern Uyghur continues the Karluk speech of the Kara-Khanid realm and the Chagatai tradition, not Old Uyghur directly; the old name was revived for the modern people in 1921.

## Commits on this branch

Each commit is one historical event.

- **c. 1400**: Chagatai-speaking oasis towns of the Tarim Basin
- **c. 1450**: Merge Qocho Uyghur heritage into the Tarim Basin population as Turfan becomes Muslim (15th c.)
- **1514**: Yarkent (Saidiya) Khanate
- **1921**: Tashkent congress revives the name 'Uyghur' for the Turkic oasis population

Run `git log --oneline karluk/uyghur` to see them together with the history they build on. The same list is in [`lineages/karluk--uyghur.md`](lineages/karluk--uyghur.md).
