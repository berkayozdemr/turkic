# <a href="https://commons.wikimedia.org/wiki/File:Flag_of_Turkmenistan.svg"><img src="https://upload.wikimedia.org/wikipedia/commons/thumb/1/1b/Flag_of_Turkmenistan.svg/120px-Flag_of_Turkmenistan.svg.png" alt="Flag of Turkmenistan" height="26"></a> Turkmens

`oghuz/turkmen`

| | |
|---|---|
| **Self-name** | Türkmen |
| **Where they live today** | Turkmenistan; also north-eastern Iran and northern Afghanistan |
| **Branch** | Oghuz: Southwestern Turkic, carried west by the Seljuks from the 11th century. |

The Oghuz who stayed east of the Caspian. The name "Türkmen" is first recorded in the 10th century for Muslim Oghuz in general; the modern people consolidated later. Known for tribal carpets, the Akhal-Teke horse and the poet Magtymguly.

## Commits on this branch

Each commit is one historical event.

- **c. 1000**: Oghuz groups in Central Asia become known as 'Türkmen'
- **c. 1750**: Magtymguly Pyragy shapes Turkmen literature
- **1881**: Battle of Geok Tepe; Russian conquest of Turkmen lands
- **1924**: Turkmen SSR
- **1991**: Independence of Turkmenistan (27 October)

Run `git log --oneline oghuz/turkmen` to see them together with the history they build on. The same list is in [`lineages/oghuz--turkmen.md`](lineages/oghuz--turkmen.md).
