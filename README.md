# Kyrgyz

`kipchak/kyrgyz`

| | |
|---|---|
| **Self-name** | Kyrgyz · Кыргыз |
| **Where they live today** | Kyrgyzstan and the Tian Shan; also Xinjiang and Tajikistan |
| **Branch** | Kipchak: Northwestern Turkic, from the Black Sea steppe to the Altai. |

Mountain pastoralists of the Tian Shan. Their language is classed as Kipchak, while the name links them to the medieval Yenisei Kyrgyz; how far the modern people descend from them is debated. The Manas epic is among the longest oral epics in the world.

## Commits on this branch

Each commit is one historical event.

- **c. 1510**: Kipchak-speaking tribes of the Tian Shan
- **c. 1515**: Merge Yenisei Kyrgyz roots: the Kyrgyz are established in the Tian Shan by the 16th c. (exact path debated)
- **1876**: Khanate of Kokand, including Kyrgyz lands, annexed by Russia
- **1936**: Kirghiz SSR
- **1991**: Independence of Kyrgyzstan (31 August)

Run `git log --oneline kipchak/kyrgyz` to see them together with the history they build on. The same list is in [`lineages/kipchak--kyrgyz.md`](lineages/kipchak--kyrgyz.md).
