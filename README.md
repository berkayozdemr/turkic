# Uzbeks

`karluk/uzbek`

| | |
|---|---|
| **Self-name** | Oʻzbek |
| **Where they live today** | Uzbekistan; also Afghanistan, Tajikistan, Kyrgyzstan and Kazakhstan |
| **Branch** | Karluk: Southeastern Turkic, heir to the Karakhanid and Chagatai literary tradition. |

The most numerous people of Central Asia. Uzbek continues the Karluk speech of the oasis cities and the Chagatai literary culture of Samarkand and Bukhara. The name comes from the Kipchak-speaking Shaybanid Uzbeks who arrived around 1500 and assimilated to the Karluk-speaking majority.

## Commits on this branch

Each commit is one historical event.

- **c. 1490**: Settled Chagatai-speaking Transoxiana
- **1500**: Merge Kipchak-speaking Shaybanid Uzbeks into Transoxiana (Muhammad Shaybani takes Samarkand). Modern Uzbek blends Karluk and Kipchak
- **1924**: Uzbek SSR
- **1991**: Independence of Uzbekistan (31 August)

Run `git log --oneline karluk/uzbek` to see them together with the history they build on. The same list is in [`lineages/karluk--uzbek.md`](lineages/karluk--uzbek.md).
