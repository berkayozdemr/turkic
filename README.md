# Khakas

`siberian/khakas`

| | |
|---|---|
| **Self-name** | Tadar · Хакас |
| **Where they live today** | Khakassia on the upper Yenisei, Russia |
| **Branch** | Siberian: Northeastern Turkic. A regional grouping: Sakha split off early, and only South Siberian forms a clear unit. |

A South Siberian people formed from several Yenisei groups; the name Khakas was adopted in the 1920s. They live in the old heartland of the Yenisei Kyrgyz, who overthrew the Uyghur Khaganate in 840. Fuyu Kyrgyz in north-east China is linguistically closest to Khakas.

## Commits on this branch

Each commit is one historical event.

- **1703**: Dzungars resettle part of the Yenisei Kyrgyz; those who stay are among the ancestors of the Khakas
- **1991**: Republic of Khakassia (within Russia)

Run `git log --oneline siberian/khakas` to see them together with the history they build on. The same list is in [`lineages/siberian--khakas.md`](lineages/siberian--khakas.md).
