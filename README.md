# Chuvash

`oghur/chuvash`

| | |
|---|---|
| **Self-name** | Chăvash · Чӑваш |
| **Where they live today** | Chuvashia on the middle Volga, Russia, and neighbouring regions |
| **Branch** | Oghur: Bulgharic or "r-Turkic". The first branch to split off, around the 1st century BCE. |

About a million speakers of the only living Oghur language, the closest living relative of Volga Bulgar. Chuvash keeps the "r" and "l" where other Turkic languages have "z" and "sh", the feature that gives the branch the name "r-Turkic". Most Chuvash are Orthodox Christian.

## Commits on this branch

Each commit is one historical event.

- **c. 1500**: Volga Bulgar descendants who keep an Oghur language: the Chuvash
- **1920**: Chuvash Autonomous Oblast
- **1992**: Chuvash Republic

Run `git log --oneline oghur/chuvash` to see them together with the history they build on. The same list is in [`lineages/oghur--chuvash.md`](lineages/oghur--chuvash.md).
