# Oghur (Bulgharic) branch

`oghur/trunk`

| | |
|---|---|
| **Where it was spoken** | From the eastern steppe to the Pontic steppe, the Danube and the middle Volga; today only Chuvashia |
| **Branch** | Oghur: Bulgharic or "r-Turkic". The first branch to split off, around the 1st century BCE. |

The first branch to split from the rest of the Turkic family, around the 1st century BCE. Oghur languages have "r" and "l" where all other Turkic languages have "z" and "sh", which is why the branch is also called "r-Turkic". Oghur-speaking tribes reached the Pontic steppe by the 5th century and founded Old Great Bulgaria around 632. Chuvash is the only Oghur language still spoken.

## Commits on this branch

Each commit is one historical event.

- **c. 0 CE**: Oghur (Bulghar, 'r-Turkic') branch splits off: the oldest split in the family
- **463 CE**: Onoghurs, Saraghurs and Oghurs reach the Pontic-Caspian steppe (reported by Priscus)
- **c. 632 CE**: Kubrat unites the Bulgar tribes: Old Great Bulgaria

Run `git log --oneline oghur/trunk` to see them together with the history they build on. The same list is in [`lineages/oghur--trunk.md`](lineages/oghur--trunk.md).
