# Danube Bulgars

`oghur/danube-bulgar`

| | |
|---|---|
| **Self-name** | Bulgar (archived branch) |
| **Where they lived** | Historically the lower Danube, today's Bulgaria |
| **Branch** | Oghur: Bulgharic or "r-Turkic". The first branch to split off, around the 1st century BCE. |

Turkic-speaking founders of the Bulgar state on the Danube in 681. Over the following centuries the ruling Bulgars merged with the Slavic-speaking majority, and by about 900 the state used a Slavic language. The name Bulgaria survives; the Oghur language does not, which is why this branch is drawn as archived.

## Commits on this branch

Each commit is one historical event.

- **681 CE**: Asparukh founds the Danube Bulgar state
- **864 CE**: Christianisation under Boris I; the Bulgars merge into the Slavic-speaking majority. Branch archived: no Turkic descendant (branch archived)

Run `git log --oneline oghur/danube-bulgar` to see them together with the history they build on. The same list is in [`lineages/oghur--danube-bulgar.md`](lineages/oghur--danube-bulgar.md).
