# Crimean Tatars

`kipchak/crimean-tatar`

| | |
|---|---|
| **Self-name** | Qırımtatar · Qırımlı |
| **Where they live today** | Crimea; large communities in Türkiye, Uzbekistan and Romania |
| **Branch** | Kipchak: Northwestern Turkic, from the Black Sea steppe to the Altai. |

The indigenous Turkic people of Crimea. Their language is Kipchak, with a southern dialect of Oghuz origin. The Crimean Khanate lasted from 1441 to 1783. In 1944 the whole people was deported to Central Asia; most were able to return only from the late 1980s.

## Commits on this branch

Each commit is one historical event.

- **1441**: Crimean Khanate (Hacı Giray)
- **1783**: Crimea annexed by the Russian Empire
- **1944**: Deportation of the Crimean Tatars (Sürgünlik)

Run `git log --oneline kipchak/crimean-tatar` to see them together with the history they build on. The same list is in [`lineages/kipchak--crimean-tatar.md`](lineages/kipchak--crimean-tatar.md).
