# Oghuz branch

`oghuz/trunk`

| **Where it is spoken** | From Turkmenistan and north-eastern Iran across Azerbaijan and Türkiye to the Balkans and Moldova |
| **Branch** | Oghuz: Southwestern Turkic, carried west by the Seljuks from the 11th century. |

Southwestern Turkic. The Oghuz confederation formed in the 8th century and built the Oghuz Yabgu state between the Caspian and Aral seas. From the 11th century the Seljuks carried Oghuz speakers west into Iran, the Caucasus and Anatolia. Turkish, Azerbaijani, Turkmen and Gagauz are the main Oghuz languages today.
