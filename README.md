# Sakha (Yakuts)

`siberian/sakha`

| | |
|---|---|
| **Self-name** | Sakha · Саха |
| **Where they live today** | Sakha Republic (Yakutia), north-eastern Siberia, Russia |
| **Branch** | Siberian: Northeastern Turkic. A regional grouping: Sakha split off early, and only South Siberian forms a clear unit. |

The northernmost Turkic people: horse and cattle breeders in one of the coldest inhabited regions on Earth. The Sakha-Dolgan line probably separated early from the rest of Common Turkic; the people moved north to the Lena between the 13th and 15th centuries. Their summer festival is Yhyakh.

## Commits on this branch

Each commit is one historical event.

- **c. 1300**: Ancestors of the Sakha (Yakuts) migrate north to the Lena (13th-15th c.)
- **1632**: Russian fort of Yakutsk founded
- **1922**: Yakut ASSR
- **1992**: Republic of Sakha (Yakutia)

Run `git log --oneline siberian/sakha` to see them together with the history they build on. The same list is in [`lineages/siberian--sakha.md`](lineages/siberian--sakha.md).
