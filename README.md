# <a href="https://commons.wikimedia.org/wiki/File:Flag_of_Kazakhstan.svg"><img src="https://upload.wikimedia.org/wikipedia/commons/thumb/d/d3/Flag_of_Kazakhstan.svg/120px-Flag_of_Kazakhstan.svg.png" alt="Flag of Kazakhstan" height="26"></a> Kazakhs

`kipchak/kazakh`

| | |
|---|---|
| **Self-name** | Qazaq · Қазақ |
| **Where they live today** | Kazakhstan; also Xinjiang (China), western Mongolia and Uzbekistan |
| **Branch** | Kipchak: Northwestern Turkic, from the Black Sea steppe to the Altai. |

Heirs of the steppe nomads, traditionally organised in three zhuz (hordes). The Kazakh Khanate formed around 1465 when groups broke away from the same Uzbek ulus whose remainder later went south with Shaybani. Kazakhstan, independent since 1991, is the largest Turkic state by area.

## Commits on this branch

Each commit is one historical event.

- **c. 1465**: Kerey and Janibek found the Kazakh Khanate
- **1731**: Junior Juz accepts Russian protection
- **1936**: Kazakh SSR
- **1991**: Independence of Kazakhstan (16 December)

Run `git log --oneline kipchak/kazakh` to see them together with the history they build on. The same list is in [`lineages/kipchak--kazakh.md`](lineages/kipchak--kazakh.md).
