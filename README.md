# Altaians

`siberian/altai`

| | |
|---|---|
| **Self-name** | Altay-kizhi · Алтай |
| **Where they live today** | Altai Republic, Russia |
| **Branch** | Siberian: Northeastern Turkic. A regional grouping: Sakha split off early, and only South Siberian forms a clear unit. |

Peoples of the Altai mountains, the region often seen as the cradle of the early Türks. Southern Altai is close to Kipchak by vocabulary, Northern Altai to the other South Siberian languages. The area became the Oyrot Autonomous Oblast in 1922 and has been the Altai Republic since 1992.
