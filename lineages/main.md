# main

- **c. 200 BCE**: Proto-Turkic speech community on the eastern steppe (Mongolia / southern Siberia)
- **552 CE**: Bumin Qaghan founds the First Turkic (Göktürk) Khaganate, the first state to carry the name 'Türk'
- **603 CE**: Göktürk Khaganate divides into Eastern and Western khaganates
- **682 CE**: Second Turkic Khaganate (Ilterish Qaghan)
- **732 CE**: Orkhon inscriptions (Kül Tegin 732, Bilge Qaghan 735): the oldest long texts in a Turkic language
